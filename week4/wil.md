***1. 회고하기(4주차)***

GDG 기초 웹 스터디 4주차에서는 API 통신, SEO, 웹 접근성의 핵심 개념을 학습했다.
API는 데이터 요청 방식인 GET과 데이터 전송 방식인 POST가 대표적이며, 요청과 응답은 헤더와 바디(주로 JSON 양식)로 구성된다. SEO(검색 엔진 최적화)는 구글 등 검색 엔진 상위에 노출되기 위한 전략으로, 신뢰할 수 있는 고품질 콘텐츠와 타 사이트에서 참조되는 백링크가 중요하다. 기술적으로는 robots.txt와 sitemap.xml을 통해 검색 로봇의 접근 범위와 사이트 구조를 알려야 한다.
또한 모든 사용자가 차별 없이 웹을 이용할 수 있도록 웹 접근성과 표준 준수의 중요성을 강조했다. 스크린 리더가 내용을 올바르게 읽을 수 있도록 , 와 같은 시맨틱 태그를 사용하고, 이미지에는 대체 텍스트(alt)를 제공해야 한다. 리액트 환경에서는 SEO 향상을 위해 서버 사이드 렌더링(SSR) 기술을 활용할 수 있다.

***3. 멘토 평가***

어려운 내용도 항상 쉽게 풀어서 설명해주셔서 따라가는 데 큰 어려움 없이 스터디를 진행할 수 있었습니다. 
특히 이론과 실습의 비중이 적절하게 구성되어 있어서 좋았습니다. 이론만 들었으면 지루하고 막연했을 것 같고, 실습만 했으면 코드의 의미를 모른 채 그냥 따라 치기만 했을 텐데, 두 가지가 균형 있게 섞여 있어서 훨씬 효과적으로 배울 수 있었던 것 같습니다.
사실 처음에는 그냥 복붙하면서 따라가기만 하는 느낌이라 '이게 진짜 내 것이 되고 있는 걸까' 하는 걱정이 들기도 했습니다. 그런데 매주 설명을 듣다 보니 어느 순간부터는 코드 한 줄 한 줄의 의미가 조금씩 눈에 들어오기 시작했고, 지금은 완벽하게는 아니더라도 '이 코드가 왜 이렇게 작성됐는지', '이 부분이 어떤 역할을 하는지' 정도는 스스로 생각해볼 수 있게 된 것 같아 뿌듯합니다.
개발에 대한 배경지식이 1도 없는 문과생 입장에서도 충분히 이해할 수 있을 만큼 차근차근 설명해주셔서, 아무것도 모르는 저에게 정말 좋은 스터디였습니다.
